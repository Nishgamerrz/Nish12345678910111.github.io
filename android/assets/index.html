Make the TV host it by itself

  1. Install Termux on the TV (first-run setup needs internet).
  2. Paste the setup command into Termux once — it installs Python, GNU Screen and Console Manager, then hooks the host to power-on.
  3. Turn on Start on boot in the Setup tab so this app opens itself after the TV powers on.
  4. The host then loads automatically; other devices open http://<tv-ip>:5000.
